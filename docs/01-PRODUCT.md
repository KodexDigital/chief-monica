# Product overview

This is a static memorial website for Chief Mrs. Monica Edumongren Zisine Otoro, 1941 — 2026. The website is intended to preserve her legacy, warm family memories, and the values she embodied.

## Goals

- Tell her story respectfully and elegantly
- Highlight family values and remembrance
- Present a strong memorial presence without backend complexity
- Keep the project editable by family members using local files
